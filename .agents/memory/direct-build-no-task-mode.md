---
name: Direct build mode preference
description: User wants implementation handled directly unless they explicitly request task planning.
---

Stay in direct build mode for user requests. Do not enter task mode, create project tasks, or offer task drafts unless the user explicitly asks for task planning or task creation.

**Why:** The user prefers direct implementation and does not want task workflow overhead for ordinary build requests.

**How to apply:** Treat clear implementation briefs as authorization to inspect, edit, and verify the code directly. Ask clarifying questions when requirements are ambiguous, but do not convert the work into a project task unless explicitly requested.
