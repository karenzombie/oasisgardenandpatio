# Reply to Agent: Gate 1b confirmed, proceed to Gate 2

Gate 1b looks good. Admin/staff protection is sound (client redirect plus API
auth on every endpoint), and the plan to pass all /admin, /agent, /staff paths
through unenriched is correct. Proceed to Gate 2 with the following.

## Path selection must be an allowlist, not a blocklist

Enrich ONLY paths that explicitly match the known public storefront patterns
(e.g. `/`, `/shop`, `/shop/:slug` for categories/manufacturers, `/product/:slug`,
and any other confirmed public routes). Everything else passes through to the
plain, unmodified index.html with no enrichment and no DB lookup.

Do NOT implement this as "enrich everything except /admin, /agent, /staff." An
allowlist fails safe: if a new staff or internal route is added later, an
allowlist simply never touches it, whereas a blocklist would start enriching it
the moment someone forgets to update the list. This matters especially because
the robots.txt Disallow rules are out of scope here and do not exist yet, so
right now this allowlist is the only thing keeping staff paths out of enrichment.

If a request path does not clearly match a known public pattern, pass it through
unenriched (fail safe), do not guess.

## Gate 2 scope (unchanged from the brief, restated with the confirmed rules)

Product detail pages. Server-side injection into the first HTTP response, via the
existing Express server, with static assets on the fast path.

- Title: product name + " | Oasis Garden & Patio".
- Description priority: short_description if non-empty; else trimmed plain-text
  description; else a name + collection + category template. ~150-160 chars, no
  HTML, no fabricated claims.
- Canonical: clean product URL, no filter/tracking params.
- Open Graph: og:title, og:description, og:image (primary image), og:url,
  og:type=product.
- Escape all injected values (quotes, ampersands) so a name like
  `Dominion Rectangular Dining Table 42" x 68"` cannot break the markup.
- noindex rule: if `catalog_visible = false` OR `is_active = false`, emit
  `<meta name="robots" content="noindex">` and NO enriched metadata (generic
  title only). Add `catalog_visible` to the by-slug response to support this (the
  only API change authorized).
- Cache metadata per slug with a TTL or invalidation hook; report the approach.
- Static fallback: any lookup failure/timeout serves the plain index.html and
  never blocks the page. Test this.
