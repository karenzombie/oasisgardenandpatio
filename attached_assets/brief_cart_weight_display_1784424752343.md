# Brief: Show estimated weight on the Cart page order summary

## Goal
The checkout Order Summary already shows an "X lb estimated" line under Shipping.
The Cart page Order Summary does not. Add the same line to the Cart page. The server
already computes the number in the cart route, so this only exposes it through the API
response and renders it.

## Behavior decision (already made, do not change without asking)
Mirror checkout exactly: show the line only when weight is greater than 0. At 0 lb,
render nothing (no "0.0 lb").

## Do not
- Do not touch the checkout page. It already works.
- Do not recompute weight or change any shipping math. The value already exists.
- Do not sync anything to prod. This is dev-only. Karen handles deploys.
- Do not hand-edit generated files. The zod/orval output is regenerated by codegen.

---

## Step 1: Add the field to the OpenAPI spec

File: `lib/api-spec/openapi.yaml`, schema `CartResponse`.

Under `properties`, immediately after the existing `shippingWeightAmount` property,
add:

```yaml
        shippingWeightLbs:
          type: number
          minimum: 0
          description: Total billable cart weight used to pick the by-weight tier.
```

Then in that same schema's `required` list (which currently ends with
`- shippingWeightAmount`), add:

```yaml
        - shippingWeightLbs
```

This mirrors the field already defined on `CheckoutQuoteResponse`.

**STOP.** Paste the diff of the `CartResponse` block and wait for confirmation before
running codegen.

## Step 3: Return the value from the cart route

File: `artifacts/api-server/src/routes/cart.ts`.

Find the `GetCartResponse.parse({ ... })` return object (it currently sets `items`,
`itemCount`, `subtotal`, `shipping`, `shippingWeightAmount`). Add one line:

```ts
    shippingWeightLbs: shippingResult.totalWeightLbs,
```

`shippingResult` and its `totalWeightLbs` already exist in that function. Do not
compute anything new. `totalWeightLbs` is a number; pass it as-is (no `.toFixed`),
matching how the checkout quote returns it.

---

## Step 4: Render it on the Cart page

File: `artifacts/web/src/pages/Cart.tsx`.

(a) Near the top of the component where `const shipping = Number(data?.shipping ?? 0);`
is defined, add:

```ts
  const shippingWeightLbs = Number(data?.shippingWeightLbs ?? 0);
```

(b) In the Order Summary, immediately after the Shipping row (the `<div>` containing
the "Shipping" `<dt>` and its `formatMoney(String(shipping))` `<dd>`), insert:

```tsx
                {shippingWeightLbs > 0 ? (
                  <p className="text-[11px] text-muted-foreground -mt-1">
                    {shippingWeightLbs.toFixed(1)} lb estimated
                  </p>
                ) : null}
```

This is the same markup and styling the checkout Order Summary uses, so the two pages
match visually.

walkthrough.
