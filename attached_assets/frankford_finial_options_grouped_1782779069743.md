# Frankford Finial Options -- Grouped Agent Brief

Finials are not sold as standalone products. They are an additional customer-selectable option on each umbrella PDP, similar to how fabric and finish work. The agent needs to add a "Finial" selector to the applicable umbrella products using the groupings below.

Pricing rule: MSRP upcharge x 0.90, rounded UP to the next whole dollar (ceil).

---

## Group 1: Greenwich Giant G-Series
Applies to: 880CAM (13ft Oct), 883CAM-SQ (10x10 Sq), 882CAM-R (8.5x11 Rect)

- Default: **Chrome Vertex (VF)** -- included, $0
- Optional free: **Chrome Ball (BF)** -- $0
- Optional upcharge: **SS Vertex (SS-VF)** -- +$30 MSRP / +$27 sale
- Optional upcharge: **SS Ball (SS-BF)** -- +$30 MSRP / +$27 sale

## Group 4: Monterey Fiberglass Market (all three lift types)
Applies to:
- Pulley (845FM, 854FM, 864FM, 454FM-SQ, 864FM-SQ)
- Crank/No Tilt (845FMC, 854FMC, 864FMC, 454FMC-SQ, 864FMC-SQ, 882FMC-R)
- Crank/Auto Tilt (845FMA, 854FMA, 864FMA, 454FMA-SQ, 864FMA-SQ, 876FMA-R)

Customer must make a selection -- both options are free, no upcharge.

- Default: **TPU Classic Ball (BF)** -- $0. Auto-matches frame color, no finish picker needed.
- Optional free: **TPU Vertex (VF)** -- $0. Also auto-matches frame color, no finish picker needed.

Note: TPU finials are tonal frame-color matches. No Chrome or SS finial options are available for this line.
